# 学术贡献清单与发表评估

> 基于 v3 趋势修正版全部实验结果，诚实评估

## 一、贡献清单

### 贡献 A：增长趋势注入（模型修正）

**方法**：从历史数据（2000–2023）计算每个国家的年均产品多样性变化率，
作为外生趋势注入 ABM 动态。正趋势国家每步随机新增能力，负趋势国家随机移除。

**效果**：
| 指标 | 修正前 | 修正后 | 改善 |
|---|---:|---:|---:|
| 整体 MAE | 57.8 | 18.6 | 67.8% |
| CHN 误差 | -135 | -60 | 55% |
| HKG 误差 | +170 | -18 | 89% |

**诚实评估**：
- **新颖性：低–中**。本质是"线性趋势外推"注入模型，方法论上并不复杂。
  类似做法在人口预测、宏观经济预测中常见（detrending）。
- **效果：显著**。MAE 改善 67.8%，但改善来源是"把历史趋势投射到未来"，
  与 naive persistence（52.1）相比，ABM 趋势修正版（18.6）的增量主要来自趋势项，
  而非 ABM 动力学本身。
- **根本问题**：趋势注入是**非结构化修正**——它不解释*为什么*中国增长快
  （产业政策？FDI？教育投资？），只捕捉了"确实在增长"这一事实。
  模型仍低估 CHN 60 产品（实际 585 vs 预测 525）。
- **可发表性**：单独不足以支撑论文。需要与结构性贡献组合。

### 贡献 B：语义产品空间（LLM 嵌入增强）

**方法**：用三种嵌入方法（TF-IDF / 千问 text-embedding-v2 / Sentence Transformer）
编码 1242 个产品的 UN 英文描述，构建语义 proximity 矩阵，与统计 proximity 融合。

**效果**（趋势修正后模型上）：
| 方法 | 嵌入维度 | 最优 α | 留出 MAE | 改善 |
|---|---:|---:|---:|---:|
| TF-IDF | 5000 (稀疏) | 0.8 | 17.5 | 2.9% |
| 千问 Qwen | 1536 | 0.6 | 17.6 | 2.3% |
| Sentence Transformer | 384 | 0.8 | 18.0 | 0.3% |
| 基线（纯统计+趋势） | — | 1.0 | 18.1 | — |

**诚实评估**：
- **新颖性：高**。首次将 LLM/文本嵌入引入经济复杂度 ABM 的产品空间构建。
  在文献中未见先例。
- **效果：一致但微小**。三种方法方向一致（均改善），但绝对改善仅 0.1–0.6 MAE 点。
- **反直觉发现有价值**：TF-IDF（最简单）> 千问 > ST（最复杂）。
  解释：高维稀疏嵌入的精确关键词匹配对产品分类更有效，
  而稠密嵌入捕捉的"深层语义"对产品空间并无额外价值。
- **致命弱点**：
  1. **缺少统计显著性检验**——2.9% 改善是否显著？未做 bootstrap 或 paired t-test。
  2. 仅 6 个 α 值网格搜索，无交叉验证，可能过拟合。
  3. 改善幅度太小（0.5 MAE 点），实际意义有限。
- **可发表性**：概念新颖，但需要统计检验支撑。是最有论文潜力的贡献。

---

### 贡献 C：贸易战验证（真实事件对照）

**方法**：以 2018 中美贸易战为自然实验，模拟半导体封锁/广泛封锁/强封锁场景，
与 CHN 实际多样性变化对比。

**效果**：
| 场景 | CHN 2023 | 效果 |
|---|---:|---:|
| 实际 | 585 | — |
| 基线（趋势修正） | 525 | 误差 -60 |
| 半导体封锁（5品） | 524 | -1 |
| 广泛封锁（17品） | 519 | -6 |
| 强封锁（17品×0.5） | 517 | -8 |

**诚实评估**：
- **新颖性：中**。用 ABM 做政策反事实分析是标准用法，但对照真实贸易战事件有故事性。
- **效果：方向正确但量级不足**。封锁确实抑制 CHN 增长（方向对），
  但 -6 到 -8 的效果 vs 实际 +54 的增长，说明模型严重低估了贸易战的影响。
- **根本问题**：模型缺少贸易战的二阶效应——
  供应链重组、技术脱钩的长期动态、替代市场效应等。
  封锁只通过"暴露衰减"影响投资概率，机制太弱。
- **可发表性**：作为案例研究有价值，但需承认模型局限性。

---

### 贡献 D：预测力 Benchmark 对比

**效果**：
| 模型 | 留出 MAE |
|---|---:|
| ABM（趋势+语义） | 17.5 |
| ABM（趋势+统计） | 18.1 |
| ABM（无趋势） | 49.1 |
| 不变假设 | 52.1 |
| 线性外推 | 71.5 |
| 全球均值 | 91.6 |

**诚实评估**：
- **新颖性：低**。Benchmark 对比是标准做法。
- **问题**：缺少与计量经济学方法的对比（面板 VAR、动态面板 GMM、
  贝叶斯结构模型等）。仅与 naive baseline 比较有"打稻草人"之嫌。
- **可发表性**：辅助材料，不构成独立贡献。

---

### 贡献 E：ABC-SMC 校准（失败）

**效果**：epsilon 收缩 9%，但校准后参数不如默认参数。

**诚实评估**：
- **诊断价值**：揭示了参数不可识别性问题——不同参数产生相似宏观输出。
- **可发表性**：作为方法论教训有价值，但"校准失败"本身不是正面贡献。

---

### 贡献 F：异质预算 vs 同质预算

**效果**：MAE 49.4（同质） vs 49.1（异质），差异 < 1%。

**诚实评估**：
- **结论**：GDP 异质预算几乎无效果。
- **可发表性**：负面结果，工程改进，不构成学术贡献。

## 二、总体发表评估

### 2.1 当前状态

| 维度 | 评分 | 说明 |
|---|---|---|
| **数据与工程** | ★★★★☆ | Harvard Atlas 24国×1242产品，管线完整，22个测试 |
| **方法新颖性** | ★★★☆☆ | 语义嵌入有新意，趋势注入较常规 |
| **实验严谨性** | ★★☆☆☆ | 缺统计检验、缺计量对比、缺交叉验证 |
| **效果量级** | ★★☆☆☆ | 语义改善 2-3%，贸易战效果 -6~-8，量级偏小 |
| **叙事完整性** | ★★★☆☆ | 有故事但模型根本局限未解决（CHN 仍低估 60） |

### 2.2 可投稿方向

| 目标 | 可能性 | 条件 |
|---|---|---|
| **Workshop 短文**（4页） | **可行** | 当前状态即可，聚焦"语义增强产品空间" |
| **计算经济学期刊**（JED, JEE) | 困难 | 需补充：统计检验 + 计量对比 + 更大国家样本 |
| **AI+社会科学**（AAAI/ICWSM) | 困难 | 需补充：语义方法理论分析 + 消融实验 |
| **Nature/Science 子刊** | 不可行 | 模型太简化，缺少真实贸易数据验证 |

### 2.3 达到 Workshop 短文需补充

1. **Bootstrap 统计检验**：语义改善 2.9% 是否显著？（p < 0.05?）
2. **多 seed 鲁棒性**：seed=42 单一运行，需 seed ∈ {42, 123, 456, 789, 2024} 取均值±标准差
3. **α 选择方法**：用交叉验证替代网格搜索

### 2.4 达到正式期刊需额外补充

4. **计量经济学对比**：面板 VAR、动态面板 GMM
5. **更大样本**：24 国 → 100+ 国（Harvard Atlas 支持）
6. **消融实验**：逐一关闭趋势/语义/政策模块
7. **理论分析**：为什么语义嵌入有效？信息论/几何解释

### 2.5 核心叙事建议

**最佳论文角度**：

> "语义产品空间：用文本嵌入增强经济复杂度 ABM"
>
> - 核心创新：三种嵌入方法首次引入产品空间
> - 反直觉发现：TF-IDF > LLM（简单优于复杂）
> - 应用展示：贸易战反事实分析
> - 诚实承认：效果量级有限，但方向一致

**不建议的角度**：
- "增长趋势注入"——太常规，不是核心创新
- "贸易战预测"——模型效果太弱，反而暴露局限

## 三、结论

**当前项目状态**：有 1 个核心创新点（语义产品空间）+ 2 个辅助发现（趋势修正、贸易战验证），
但缺少统计检验和对比实验。

**最短路径发表**：Workshop 短文（4页），聚焦语义产品空间，补充 bootstrap 检验。

**冲击正式期刊**：需 2-3 周补充计量对比、扩大样本、统计检验。
