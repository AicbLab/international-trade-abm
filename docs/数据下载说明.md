## 当前结论

已下载 **8 个原始文件，共 531,050,821 字节（约 531.05 MB）**，可作为研究计划第一阶段的数据输入。尚未清洗、插补、裁剪研究样本，也未开始建模。

- 主数据：Harvard Growth Lab 基于 UN Comtrade 清洗与协调后的 **HS 1992、4 位码**贸易数据；不是未经处理的 UN Comtrade 原始申报数据。
- 实际文件覆盖 **1995–2024 年**，包含计划要求的 **2000–2023 年**。后续研究切片须显式限制年份，不把 2024 年混入样本。
- 主贸易表共 **6,752,528 行**，其中 2000–2023 年为 **5,490,943 行**。
- 原始表出现 **232 个国家、地区及特殊代码**、**1,243 个产品代码**；其中 **1,242 个是纯数字四位码**，另有特殊代码 `XXXX`。
- 223 个国家／地区代码在 2000–2023 年每年均有记录；这只表示年度记录存在，不表示各产品均完整或缺失记录等于零贸易。
- **传输完整性检查通过；研究输入质量检查为 `needs_attention`**，原因是原始数据中有特殊代码及负贸易值，详见下文。

主贸易表的字段：

```text
country_id, country_iso3_code, product_id, product_hs92_code, year,
export_value, import_value, global_market_share, export_rca,
distance, cog, pci
```

`export_value` 和 `import_value` 为当年美元（current USD）。HS 产品编码须按字符串读取，例如 `0101`，不能丢失前导零。

`distance` 是国家进入某产品的距离指标，**不是产品—产品的 proximity 矩阵**。产品空间网络仍需按研究方案另行构建。

## 来源、版本与许可

### Harvard Growth Lab 主数据

- 数据集：[International Trade Data (HS, 92)](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/T4CHWJ)。
- DOI：`10.7910/DVN/T4CHWJ`。
- 本次下载版本：**18.0**；发布于 2026-04-22。
- 元数据许可：**CC0 1.0**；论文中仍应规范引用数据集及其方法。
- [官方数据与方法说明](https://atlas.hks.harvard.edu/data-downloads/)。
- 该版本元数据的时间范围字段仍写到 2023 年，但实际 CSV 扫描发现 2024 年记录；本记录按文件内容报告覆盖范围。
- 下载保留完整全球数据，避免提前仅保留亚太样本后改变 RCA 的全球参照。后续再确定 20–30 个研究国家和 500–800 种产品。

### 2022 年整合数据库：与计划描述的差异

原计划给出的 DOI 对应：

> Patelli, A., Pietronero, L. & Zaccaria, A. (2022). Integrated database for economic complexity. Scientific Data, 9, 628. https://doi.org/10.1038/s41597-022-01732-5

依据[论文 Data Records 与 Methods](https://www.nature.com/articles/s41597-022-01732-5)：

- 实际仓储是 **Figshare**，不是 Zenodo。
- 数据 DOI：[`10.6084/m9.figshare.20167700.v1`](https://doi.org/10.6084/m9.figshare.20167700.v1)；许可 **CC BY 4.0**。
- 文中整合口径是 **1996–2018 年、两位码货物加服务业**，不是计划写的 1995–2020 年 HS4 主数据。
- Fitness/Complexity 与本项目使用的 ECI/PCI 不能直接视为同一指标。因此单独存放，仅作补充与方法对照。

### UN Comtrade 代码表

通过公开参考数据端点下载，无需账户：

- https://comtradeapi.un.org/files/v1/app/reference/Reporters.json
- https://comtradeapi.un.org/files/v1/app/reference/H0.json

这些文件未提供用于本次核对的官方校验和；已验证 JSON 结构并记录本地 MD5/SHA256，不将本地哈希冒充官方校验和。

## 校验结果与后续清洗注意事项

### 文件完整性

- 5 个 Harvard 文件和 1 个 Figshare 文件均与官方声明的大小、MD5 一致。
- 8 个文件均记录 SHA256，并重新读取核对本地大小与哈希。
- Figshare 压缩包通过逐成员 CRC 检查。
- 对 5 个 CSV 做了流式解析、字段数量、年份、代码形式和数值检查。
- 尚未检查主键重复、贸易会计恒等式、跨表数值一致性或经济合理性，不能将本次检查等同于完整数据清洗。

### 原始数据中保留的问题

1. **非标准四位码 `XXXX`**：主贸易表共 3,114 行，2000–2023 年内 2,629 行；产品年度表共 30 行，研究期内 24 行。后续应明确它在产品集合和贸易分母中的处理规则，不能简单当作普通产品节点。
2. **负贸易值**：`ANS` 在 2020 年的 `2709` 进口值为 `-325450001` 美元；国家年度表及双边总额表有相应记录。原样保留，未直接改零或删除。
3. **缺失指标**：国家年度表有 6 个空 ECI；主贸易表有 17 个空 RCA。此处统计为完整下载期，未插补。
4. **国家年度覆盖不齐**：`ANS`、`ANT`、`BES`、`BLM`、`CUW`、`MNE`、`SRB`、`SSD`、`SXM` 未覆盖全部研究年份；具体缺失年份见检查报告。不得将历史地区变动一律理解成随机缺失。
5. **国家代码表并非完全一致**：14 个 Atlas 代码在本次 UN 报告方表中未匹配到名称：`ANS, ASM, ATA, ATF, BVT, CCK, CXR, FLK, GUM, HMD, NFK, PCN, SGS, TWN`。保留原代码与空名称，不自动合并或删除。

因此 `validate_data.py` 当前返回退出码 **1**，并写出 `needs_attention`。这是主动暴露数据内容问题，**不是下载损坏或传输失败**。

## 可复用脚本与检查产物

在项目根目录运行，仅使用 Python 标准库：

```powershell
python scripts/download_data.py
python scripts/validate_data.py
```

也可以单独补下代码表：

```powershell
python scripts/download_data.py --source references
```
